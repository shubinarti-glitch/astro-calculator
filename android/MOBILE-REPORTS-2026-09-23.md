# Отчёты об ошибках — локальный этап

## Реализовано

Кнопка кабинета отправляет описание на `POST /api/mobile/reports` вместо копирования в буфер. Требуется отдельная галочка согласия. Отправляются только описание, случайный ID обращения, версия/код приложения, канал сборки и Android API. После подтверждения сервера показывается номер обращения. При сетевой ошибке текст остаётся в форме; повтор в той же форме использует тот же ID.

Сервер не сохраняет токен, IP, имя, почту или карты в записи отчёта. Пользователь может сам вписать личные сведения в описание — форма предупреждает не делать этого. Обычные серверные access-логи регулируются отдельно; их конфигурация этим изменением не менялась.

Ограничения: описание 5–2000 символов, тело до 16 KiB, 5 попыток в час на IP, максимум 1000 записей. Записи старше 30 дней исключаются и удаляются при следующем чтении/записи; это не фоновое удаление ровно по таймеру. Новое хранилище `data/mobile-reports.json` закрыто от Git существующим правилом `/data/`. Основная БД и секреты не изменяются.

Просмотр последних 100 обращений: `GET /api/admin/mobile-reports`, с существующей проверкой администратора и `Cache-Control: no-store`. Это защищённый JSON API; отдельная страница админки пока не добавлена. Описания — недоверенный пользовательский текст, при будущем выводе использовать textContent, не innerHTML.

## Ограничения этапа

- Автоматический перехват JVM-вылетов добавлен следующим локальным этапом (CRASH-DIAGNOSTICS-2026-09-23.md); ANR не охвачены. На устройстве перехват ещё не проверен.
- Скриншоты, логкат, содержимое исключений и натальные данные не собираются.
- Хранилище рассчитано на один процесс сервера; перед деплоем проверить число production workers. Для нескольких процессов требуется межпроцессная синхронизация или иное хранилище. Внутрипроцессная блокировка защищает параллельные потоки.
- Сквозная проверка на устройстве ещё не выполнена.
- API ещё не развёрнут на astrosmap.ru: текущая установленная версия приложения не получила эту функцию.
- Перенос оставшихся встроенных авторских материалов на API остаётся блокером release-сборки.
