# Перенос Android-текстов на API

## Изменено локально

- app/build.gradle.kts: удалена задача генерации AndroidEditorial и подключение её исходников. Закрытый JSON больше не вход сборки.
- backend/mobile_editorial.py, backend/main.py: новый GET /api/mobile/editorial/v1. Сервер читает закрытый data/editorial/android-v1.json, проверяет схему и стабильный порядок карт. Нет переноса текстов в исходники. Отсутствующий/повреждённый пакет возвращает 503 без путей/данных, успешный ответ — Cache-Control: no-store.
- editorial/RemoteEditorial.kt, data/api/AstroApi.kt: загрузка с ограничением времени, в памяти процесса, без записи на диск; при ошибке — сброс в нейтральные сообщения.
- TarotDeck.kt: 78 стабильных ID и расчёт старшинства сохранены. Поля карточек теперь читаются из загруженного ответа, включая уже выбранные карты.
- LunarTexts.kt: советы/трактовки по фазам и знакам приходят из API. Названия фаз и эмодзи — интерфейсные подписи, остаются локально.
- MainActivity.kt: загрузка при onResume. DailyNotify.kt и WidgetUpdateWorker.kt: загрузка перед формированием уведомлений/виджетов.
- AndroidEditorialTest.kt и tests/test_mobile_editorial.py: проверка ID, нейтральных сообщений, обновления карточек, ошибки сети и серверного контракта. Новые тестовые тексты синтетические, не авторские.
- EDITORIAL-CONTENT.md обновлён после проверки прежней схемы.

## Что это не означает

Это не удаляет тексты из старых APK, прежних build-каталогов, пользовательских сохранённых раскладов или уже показанных уведомлений. Полученные по сети тексты остаются в оперативной памяти до следующего обновления/выхода процесса. Полного аудита всех остальных текстовых источников приложения и финального APK/AAB пока нет. Не заявлять полное отсутствие редакционных материалов во всех артефактах только на основании компиляции.
