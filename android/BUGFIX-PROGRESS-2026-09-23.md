# Исправления Android — промежуточный отчёт

## Изменено локально

- `AstroApi.kt`: поля согласий RegisterRequest обязательны, без значений по умолчанию; поэтому сериализатор не пропускает их.
- `AccountScreen.kt`, `AccountViewModel.kt`: передаются фактические значения двух чекбоксов; отправка при отсутствии согласия блокируется. Ошибки проверки полей показываются понятными RU/EN сообщениями, без содержимого input из ответа сервера.
- `RegisterRequestTest.kt`: проверка всех пяти полей согласия и сохранения false при сериализации.
- `ForecastScreen.kt`: вместо общей фразы показываются highlights из ответа сервера: дата, участники, название аспекта, пояснение. Авторские трактовки не добавлялись в исходники.
- `values/forecast_details.xml`, `values-en/forecast_details.xml`: нейтральные интерфейсные сообщения при отсутствии событий/пояснений.

## Проверки

Google Play debug-компиляция прошла. `:app:testGoogleplayDebugUnitTest --tests '*RegisterRequestTest'` завершился успешно: 2 теста, 0 ошибок, 0 пропусков (подтверждено XML-отчётом). Первый запуск не увидел ресурсы, добавленные после начала обработки ресурсов; успешный повторный запуск выполнен на полном наборе правок. Это целевые тесты сериализации, не весь набор тестов. Реальная регистрация и визуальная проверка прогнозов ещё не выполнены. Причина «иероглифов» отдельно не воспроизведена; исправлен подтверждённый дефект отсутствующих полей согласия.

## Осталось до релиза

1. Устранить генерацию встроенных авторских материалов, реализовать получение через API и нейтральное поведение без сети. Существующий генератор пока не удалён; release APK не собирать и не публиковать.
2. Ручная отправка обращения и защищённый API просмотра реализованы локально (см. MOBILE-REPORTS-2026-09-23.md). Добавлена диагностика JVM-вылетов с отдельным согласием; требуется сквозная проверка на устройстве (CRASH-DIAGNOSTICS-2026-09-23.md). Интерфейс админки и проверка раскрытия сбора данных ещё впереди.
3. Проверить оба варианта и сценарии на устройстве. Подготовить отчёт до коммита.

Для первого этапа регистрации/прогнозов API не менялся. На следующем этапе ручных обращений добавлены POST /api/mobile/reports и защищённый GET /api/admin/mobile-reports; для их работы потребуется согласованный деплой сервера до выпуска APK. Серверные тесты обращений: 12 прошли. Google Play debug-компиляция и полный набор его unit-тестов: 29 прошли.
