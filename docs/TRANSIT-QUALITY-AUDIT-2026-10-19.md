# Второй проход проверки трактовок транзитов — 19.10.2026

## Объём

Проверены русские авторские трактовки и английские пары из `data/authored_transit_content.json` и `data/transit_en/`. Полный корпус содержит 234 совпадающих RU/EN ключа; короткие фрагменты отдельно оценивались по смыслу, а не только по длине.

## Что выявлено

Короткие тексты сами по себе не указывают на шаблонность: пустых полей и дословных дублей в предыдущем проходе не найдено. Более явный повтор оказался в поле «Совет» у Юпитера и Нептуна. У Юпитера 14 советов повторяли три общих продолжения о еженедельной проверке результата, цене расширения или делении плана на этапы. У Нептуна 14 советов повторяли три общих продолжения о ретроградном пересмотре, отсрочке решения или проверке денег, сроков, согласия и здоровья. В обоих языках к этим продолжениям механически добавлялась тема натальной точки, из-за чего совет оставался почти взаимозаменяемым.

## Что изменено

В 28 парных RU/EN записях (14 сочетаний для каждого транзитного Юпитера и Нептуна) сохранены первые авторские предложения совета. Повторные продолжения заменены конкретными действиями для соответствующей натальной точки: бюджетом и домашними договорённостями для Луны, проверкой источников для Меркурия, распределением ответственности для Сатурна, согласованием ролей в партнёрстве для Десцендента и другими предметными шагами. Узловые трактовки, советы Хирону и Лилит, а также остальные поля не менялись.

Приватные JSON в `data/` исключены из Git по `.gitignore`; исходные копии затронутых файлов сохранены в `.tmp/transit-advice-backup-20261019/` для локального отката. Эти тексты не входят в публичный исходный экспорт и должны передаваться в рабочую конфигурацию только по штатному протоколу приватного релиза.
