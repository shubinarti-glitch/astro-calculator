## Обязательный порядок публикации

1. Публиковать только специально подготовленный исходный снимок, не весь рабочий каталог.
2. Запустить `python scripts/check_public_source.py .source-publish-20260922`. Проверяется индекс Git: одного `.gitignore` недостаточно.
3. Отдельно проверить встроенные тексты, изображения, комплектность соответствующего исходного кода и уведомления третьих лиц.
4. Не публиковать исходный снимок как окончательно очищенный, пока встроенный контент не рассмотрен. Сохранить инструкции сборки, лицензии и необходимый программный код.

## Нерешённые вопросы

- Уже опубликованные материалы остаются в истории и возможных копиях. Обычный коммит удаления историю не очищает.
- Проверить удалённую историю обоих репозиториев, ветки и теги; локальный снимок не доказывает отсутствие материалов во всех удалённых версиях.
- Установить права и прежние условия публикации для встроенных трактовок. Самостоятельные произведения можно лицензировать отдельно при наличии прав; новое уведомление не отменяет ранее предоставленные права.
- Для будущих версий вынести независимый редакционный контент в отдельный пакет данных с явно описанными условиями использования; проверить сайт, PDF и Android на сохранение поведения. Простое перемещение не гарантирует юридической независимости.
- Переписывание общей истории и `git push --force` по правилам проекта выполняет владелец вручную. Даже оно не удаляет чужие скачанные копии.
